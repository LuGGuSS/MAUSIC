Кросплатформений музичний плеєр з алгоритмами рекомендацій.

Для розгортання необхідно запустити .sln файл через зручне для вас середовище розробки яке підтримує MAUI, і запустити будівництво проєкту на необхідну платформу.

Було протестовано тільки MacOS та Android 15.
Windows скоріше за все не буде працювати через особливість файлової системи.

Присутні баги.
Якщо після додавання папки з музикою на Android нічого не відбувається - необхідно в налаштуваннях надати доступ до музики.
